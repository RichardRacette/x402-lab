`candidate.mjs` exports synchronous `evaluate({ email, dns, disposableDomains })`. Each DNS fixture maps lowercase ASCII domain names to MX/A/AAAA/TXT records with `{status, answers}`; a missing record means NODATA under the frozen fixture contract, while an absent domain means unavailable. Every output has `route`, `reason`, `status`, `mailboxExists: "UNKNOWN"`, and caller-supplied evidence. KEEP is only an intake decision; no mailbox, identity, consent or delivery assertion is made.

Implemented scope: outer-whitespace trim, common ASCII local parts, IDNA domain normalization, syntactic failures, domain-label disposable matches, MX/Null MX, NXDOMAIN, IPv4/IPv6 fallback and a reject-all SPF intake convention for fallback domains. DNS failures and inconsistent/malformed evidence go to REVIEW. SMTPUTF8, quoted/complex address syntax and domain literals explicitly go to unsupported review. List membership is review; non-membership is not a claim that a provider is non-disposable. Evidence freshness is explicitly unavailable from this fixture interface.

This is a small bespoke parser, **not a replacement for a mature RFC validator**. It has no Public Suffix List dependency; the caller supplies the pinned curated list and list matching uses full domain-label suffixes. Production IDNA/Unicode edge coverage, public-suffix validation, list refresh/rollback, network timeouts, abuse controls, DNS caching/expiry and customer integration are unverified. Resource caps here protect the fixture function only. A malformed or unknown fixture never initiates network access.

Public verification completed at **2026-09-09T05:19:25Z**: 14/14 expected routes and `mailboxExists: "UNKNOWN"` for all cases. Nine additional checks covered malformed/missing input, unknown domain, valid unsupported local formats, temporary DNS failures, malformed DNS status, and conflicting Null MX. They all preserved REVIEW. The core was frozen at this point, before heldout scoring; a failed comparison should terminate this candidate, not trigger tailoring to hidden cases.
